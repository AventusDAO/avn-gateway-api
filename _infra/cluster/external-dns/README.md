## AWS loadbalancer controller
Controls the route53 DNS entries for services that are exposed outside of the cluster be it DNS for internal or external managed zones.

the External DNS controller must have permission to create/modify Route53 records, the iam permissions are defined [here](https://github.com/Aventus-Network-Services/avn-gateway-api/blob/main/_infra/terraform/modules/k8s-service-account-permissions/external-dns.tf). Similar to the load balancer controller - we create a Kubernetes Service Account that is directly linked to an IAM role. The controller assumes this role via the kubernetes service account granting it all the necessary permissions.

The IAM role must provide a specific namespace and serviceaccount name for the principal oidc provider (created for the cluster by the eks terraform module). An example can be found [here](https://github.com/Aventus-Network-Services/avn-gateway-api/blob/41900504d0c0fd9e2b805ce770d6930081fc229a/_infra/terraform/modules/k8s-service-account-permissions/external-dns.tf#L49), notice that the IAM role can only be assumed by a kubernetes service account in the `kube-system` namespace with the name defined by the `external_dns` local variable. We tell the helm chart to use this pregenerated service account in the [values.yaml](./values.yaml)

We ensure that traffic is routed from outside the cluster by creating an externaldns annotation in its ingress manifest, Eg. https://github.com/Aventus-Network-Services/avn-gateway-api/blob/41900504d0c0fd9e2b805ce770d6930081fc229a/avn-connector/chart/templates/ingress.yaml#L7. This example shows that for the sandbox environment, the annotation `external-dns.alpha.kubernetes.io/hostname: avn-connector.sandbox.aventus.internal` will instruct the external DNS controller to create a DNS record `avn-connector.sandbox.aventus.internal`, the nginx annotation ensures that the record points to the Nginx ingress loadbalancer. A request to http://avn-connector.sandbox.aventus.internal will be routed to Nginx and proxied to the avn-connector service as defined in the Ingress.
